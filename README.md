# 🧲 冰箱贴裁剪排版工具

在浏览器里一步完成「裁剪图片 + 排版到相纸」，导出高清 PNG / JPG / PDF 直接打印。纯前端单文件，不用安装，图片不会上传到任何服务器。

## 功能

- 冰箱贴形状：方形、圆角矩形、圆形 / 椭圆，尺寸自定义（mm），可设出血
- 相纸：5寸、6寸、7寸、A6、A5、A4，也可自定义；自动选择能放更多的方向
- 裁剪：拖动移动、滚轮 / 双指缩放、旋转 90°、水平翻转
- 每张图可设打印数量，「补满整页」一键填满空位
- 裁切线：轮廓线 / 角线 / 无
- 300 / 600 dpi 导出，图片分辨率不足时会提醒
- 支持多选、拖入、Ctrl+V 粘贴图片

## 使用

在线版：https://nineh.github.io/fridge-magnet-maker/

或者下载 `index.html`，双击用浏览器打开就能用。

> 打印 PDF 时请选「实际大小 / 100%」，不要选「适合页面」，否则尺寸会变。

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`，保存后等一两分钟即可访问。
